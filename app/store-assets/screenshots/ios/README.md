# Screenshots — iOS

Pasta destinada aos screenshots do InteraZap para a App Store.

## Formatos obrigatórios

| Formato                  | Resolução | Status      |
| ------------------------ | --------- | ----------- |
| iPhone 6.9" (16 Pro Max) | 1320×2868 | ⏳ Pendente |
| iPhone 6.5" (14 Plus)    | 1284×2778 | ⏳ Pendente |
| iPhone 5.5" (8 Plus)     | 1242×2208 | ⏳ Pendente |
| iPad 13" (M4) — opcional | 2064×2752 | ⏳ Opcional |

## Telas a capturar

1. Caixa de entrada (inbox com lista de conversas)
2. Conversa de chat aberta
3. IA Autopilot em ação (resposta com raciocínio visível)
4. Painel CRM do contato
5. Notificação push recebida

## Nomenclatura

```
{numero}-{tela}-{resolucao}.png
Ex: 01-inbox-1320x2868.png
```

## Como capturar

```bash
# Via Xcode Simulator (macOS)
xcrun simctl io booted screenshot 01-inbox-1320x2868.png

# Ou usar Xcode → Window → Screenshots
```
