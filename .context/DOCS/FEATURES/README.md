# Features — InteraZap

Feature docs (descrição humana de features). Tasks executáveis ficam em `../TASKS/`.

## Convenções

- Um arquivo por feature: `[YYYY-MM-DD]-[nome-kebab].md` ou `FEAT-NNN-[nome].md`
- Template: `_TEMPLATE.md`
- ID: `FEAT-NNN` (incremental)
- Status: `Em Planning` → `Em Review` → `Em Execução` → `Concluída`

## Fluxo

1. PM cria a partir de `_TEMPLATE.md`
2. REVIEWER + ARCHITECT validam
3. ARCHITECT decompõe em tasks (`../TASKS/[nome]-tasks.md`)
4. Execução PREVC
5. PM fecha
