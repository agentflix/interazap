## Formato

Cada entrada segue:

```text

```

## Tipos

- `FEAT` — Nova funcionalidade
- `FIX` — Correção de bug
- `REFACTOR` — Refatoração sem mudança de comportamento
- `DOCS` — Documentação
- `TEST` — Testes
- `CHORE` — Configuração, tooling, infra
- `BREAKING` — Mudança que quebra compatibilidade
