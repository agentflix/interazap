## Architectural Decisions

1. **JWT HMAC local** — Gateway valida token com secret compartilhado, não precisa HTTP callback
2. **Redis Pub/Sub** — Reutiliza canal `ws.events` existente com EventFanoutService
3. **Provider WEB** — ChatTicket provider='web' para diferenciar de canais externos
4. **Socket.io rooms** — Cada sessão join room `session:{sessionId}` para broadcast direcionado
