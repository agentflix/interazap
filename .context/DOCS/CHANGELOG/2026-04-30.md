## Fix: Badge de modo do chat (IA/Chatbot/Humano)

**Arquivos:**
- `api/src/Domain/Chat/Models/ChatTicket.php`
- `api/src/Domain/Chat/Http/Resources/ChatTicketResource.php`
- `app/src/app/core/services/called.service.ts`
- `app/src/app/pages/chat/components/chat-ticket-item/chat-ticket-item.html`
- `app/src/app/pages/chat/components/chat-ticket-item/chat-ticket-item.spec.ts`

**O que mudou:**
- O badge de modo na lista de tickets agora distingue corretamente entre **IA**, **Chatbot** e **Humano**
- Campo `current_ai_agent_id` (existente na tabela desde 29/04) agora é exposto na API e utilizado no frontend
- Quando `status === 'in_progress'` → mostra **Humano**
- Quando `is_bot_active && current_ai_agent_id` → mostra **IA**
- Quando `is_bot_active && !current_ai_agent_id` → mostra **Chatbot**

**Contexto:**
Usuários sem plano de IA estavam vendo o badge "IA" mesmo quando o atendimento era apenas um chatbot/fluxo automático simples.

- Migration: `2026_04_29_000001_add_current_ai_agent_id_to_chat_tickets.php`
