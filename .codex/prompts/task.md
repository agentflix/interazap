# task — Implementar task com TACE

## Objetivo

Implementar task técnica seguindo framework TACE.

## Trigger

```
/task [descrição-da-task]
```

## Formato TACE

```
T: O que fazer
A: Onde fazer (arquivos reais)
C: Antes/depois (comportamento)
E: Como validar (teste/comando)
```

## Contexto carregado

- AGENTS.md do módulo
- Código relevante (buscar primeiro, não abrir tudo)

## Contexto NÃO carregado

- Todo projeto
- Feature docs completas

## Saída

- Código implementado
- Evidência de validação
