As duas formas de conectar o WhatsApp

Quando você conecta o WhatsApp à InteraZap, pode escolher entre dois modelos de integração distintos, cada um com suas características, custos e perfis de risco:

✅ API Oficial do WhatsApp Business (WABA)

Integração homologada pela Meta. Requer aprovação do número junto à Meta e tem custo por conversa. É a opção mais estável, sem risco de banimento do número e recomendada para operações de maior volume ou missão crítica.

📱 Conexão via QR Code (WhatsApp Web)

Integração via leitura do QR Code, da mesma forma que o WhatsApp Web funciona no navegador. Não requer aprovação da Meta e não tem custo por conversa. Funciona bem para operações menores, mas traz riscos de banimento que o Cliente precisa conhecer e aceitar.

O que é o WhatsApp "não oficial"?

O WhatsApp "não oficial" se refere a qualquer solução que se conecta ao WhatsApp sem passar pela API Oficial da Meta. A integração via QR Code funciona simulando a sessão do WhatsApp Web em um servidor, o que tecnicamente viola os Termos de Serviço do WhatsApp — da mesma forma que qualquer automação via WhatsApp Web viola.

A Meta pode detectar esse comportamento e banir o número. Isso não é uma falha da InteraZap — é uma característica inerente dessa modalidade de integração.

Riscos que você precisa conhecer antes de usar o QR Code

Se você optar pela integração via QR Code, estes são os fatores que podem levar ao banimento do seu número pelo WhatsApp:

📢

Reclamações de spam

Quando vários contatos marcam sua mensagem como spam, o algoritmo da Meta pode agir.

🤖

Padrões de automação detectados

A Meta identifica velocidade de envio, intervalos regulares e volume atípico.

🌍

IP diferente do habitual

Conexão via servidor em nuvem com IP diferente do dispositivo original é detectada como uso anômalo.

📲

Violação dos Termos de Serviço

O uso de qualquer ferramenta não homologada já é, por si só, motivo suficiente para banimento pela Meta.

📋

Envio em massa sem histórico

Disparar mensagens para contatos sem conversa prévia aumenta significativamente o risco de denúncias.

🔄

Rotatividade de sessão

Reconectar frequentemente via QR Code ou trocar de servidor é detectado como comportamento suspeito.

Atenção: O banimento de número pelo WhatsApp é, na maioria dos casos, permanente. O número banido perde o histórico de conversas e não pode ser recuperado. Esse risco existe independentemente de qual plataforma você usa para a integração via QR Code — é uma consequência da escolha do modelo operacional.

Responsabilidade pelo modelo operacional

A InteraZap disponibiliza a tecnologia de integração. A escolha do modelo — API oficial ou QR Code — é do Cliente. Ao optar pela integração via QR Code, o Cliente declara estar ciente de que:

  • Essa modalidade não é homologada pela Meta.
  • O risco de banimento do número é real e inerente ao modelo, não decorrente de falha da InteraZap.
  • A InteraZap não se responsabiliza por banimentos, perda de número, interrupção do serviço de WhatsApp ou qualquer outro dano decorrente de decisão da Meta sobre o número.
  • Em caso de banimento, a InteraZap pode apoiar a migração para a API Oficial, mas não pode reverter a decisão da Meta.

O que fazer se seu número foi banido

Se o banimento aconteceu, siga estes passos:

  1. Tente recorrer via whatsapp.com/contact. Em primeiro banimento, há chance de reversão.
  2. Desconecte imediatamente a sessão do QR Code na InteraZap.
  3. Se o recurso não for aceito, configure um novo número em dispositivo limpo (nunca banido anteriormente).
  4. Considere migrar para a API Oficial do WhatsApp Business para eliminar o risco em operações futuras.
  5. Entre em contato com a InteraZap em contato@interazap.com.br — podemos auxiliar na migração e configuração do novo número.

Boas práticas para reduzir o risco no QR Code

Se você optar pelo QR Code e quiser reduzir o risco de banimento ao mínimo:

  • Sempre obtenha consentimento antes de enviar mensagens. Use opt-in explícito.
  • Personalize as mensagens — evite disparos genéricos em massa para contatos sem histórico.
  • Ofereça opt-out fácil — menos denúncias = menor risco.
  • Construa reputação gradualmente — comece com volumes baixos e escale progressivamente.
  • Responda mensagens recebidas — uma conta que só envia e nunca responde levanta suspeitas.
  • Evite intervalos regulares demais — padrões muito mecânicos de envio são detectados mais facilmente.

Quando faz sentido usar cada opção

  • API Oficial: operações de médio e grande porte, alto volume de mensagens, missão crítica, necessidade de SLA, ou quando o risco de banimento do número é inaceitável para o negócio.
  • QR Code: operações menores, equipes em fase de teste, negócios com volume baixo de mensagens e que aceitam os riscos inerentes ao modelo.
